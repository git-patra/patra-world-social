#### Important (Should Fix)

1. **Releasing one touch cancels every held control.** `apps/web/src/activities/input-router.ts:26` installs a global `pointerup`/`lostpointercapture` handler that clears all pressed keys and releases the entire input frame. `apps/web/src/activities/ActivityHUD.tsx:14` also releases all controls on capture loss. Holding Gas with one thumb and steering with the other, then releasing steering, therefore stops Gas although its pointer remains down. The existing shell's global pointer release is another producer to account for. Track controls by pointer identity/source and release only the ending pointer; reserve full neutralization for modal, blur, hidden, disconnect and teardown. Add a production-handler test holding throttle and steering simultaneously, releasing either pointer, and checking the other remains held.

2. **Area lifecycle and resync ordering can discard or rewind authoritative state.** `apps/web/src/activities/store.ts:45` discards every same-generation update with `tick <= previous.tick`, but the world can perform RESERVED → ACTIVE within one simulation tick. Separately, `:52` unconditionally replaces the area map: while `reload()` waits for both metadata and lobby responses at `:36`, a newer lifecycle can arrive, then the older metadata reply rewinds phase or generation and temporarily restores the wrong input/scene ownership. Preserve lifecycle ordering independently of simulation tick, and fence/merge resync responses against newer accepted state and the current attachment/reconnect request. Test same-tick phase transitions plus a deferred resync resolving after a newer generation/lifecycle; avoid replaying effects for a plain resync.

3. **Penalty snapshots can move the client back to an earlier turn.** `apps/web/src/activities/store.ts:40` has a monotonic frame guard only for race; every penalty payload replaces the current state. `loadGames()` at `:39` runs asynchronous snapshot reads alongside streamed `penalty.turn_opened`/`penalty.revealed` events, so a delayed snapshot or older queued event can overwrite a later turn/reveal, restore stale controls/deadlines, and roll back the displayed score. Fence penalty state by a server revision or its monotonic public turn/phase/chosen progression, and fence obsolete read completions. Include newer-turn→older-snapshot and same-turn reveal→choosing regressions.
